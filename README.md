# Hack-Battle-
A head-to-head browser game where you race a computer rival to crack simulated "vaults." Best of 3 rounds, and the faster you solve, the more you score
## How to play
1. Enter a handle and choose a rival (Script Kiddie, Black Hat, or Zero Day).
2. Solve the puzzle in the terminal: Caesar cipher, hex decoding,
   binary conversion, or spotting the attacker IP in a log.
3. Beat the rival's timer to win the round. Hints cost 25 points.

## Built with
HTML, CSS, and JavaScript. All puzzles are fictional and run in the
browser, nothing touches real systems.

## About this project
